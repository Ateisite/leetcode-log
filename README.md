# leetcode-log

> LeetCode grinding log — one problem a day, every day counts.

## Goal

- Finish **Hot 100** in the first pass
- Move on to topic-wise practice (DP / Graph / Backtracking / ...)
- Target: **365 problems** by the end of the academic master's program

## Structure

```
leetcode-log/
├── README.md
├── hot100/            # LeetCode Hot 100
├── topics/            # Topic-wise practice
│   ├── array/
│   ├── linkedlist/
│   ├── tree/
│   ├── dp/
│   ├── graph/
│   └── ...
└── misc/              # Everything else
```

## Language

Solutions are written in **Python 3**.

## Progress

| Stage | Range | Status |

## Log Format

Each solution lives in its own file and includes:

- Problem number & title
- Difficulty
- Idea / approach in a few lines
- Time & space complexity
- The code
